# Module Outline: Python Pandas Library

## Module Title
Data Manipulation with Python Pandas

## Target Audience
Python developers and aspiring data analysts who have basic Python knowledge and want to learn data manipulation and analysis using Pandas. This module is part of a 5-day Python training session.

## Level
Intermediate

## Learning Objectives
- Explain the core data structures of Pandas (Series and DataFrame) and their use cases
- Apply Pandas functions to load, inspect, and clean real-world datasets
- Implement data filtering, sorting, and grouping operations on structured data
- Analyze datasets using aggregation, pivot tables, and statistical methods
- Design data transformation pipelines using method chaining and apply functions
- Evaluate and handle missing data using appropriate imputation strategies
- Create meaningful data summaries by merging, joining, and reshaping datasets

## Topics

1. Introduction to Pandas — What and Why
2. Pandas Data Structures — Series and DataFrame
3. Loading and Inspecting Data (CSV, Excel, JSON, SQL)
4. Data Selection and Filtering (loc, iloc, boolean indexing)
5. Data Cleaning and Handling Missing Values
6. Data Transformation (apply, map, groupby, aggregation)
7. Merging, Joining, and Reshaping Data

## Estimated Slide Count
40 slides (60-minute session)
